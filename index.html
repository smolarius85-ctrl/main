Before you open one

All three open ready to use. Nothing installs, nothing asks for an account, and no figure you type is sent anywhere: the deal sheet keeps its history in the browser it was entered in, and the job map keeps the current map the same way. The map draws tiles from Esri and falls back to Nominatim for an address its own table does not recognize. Everything else runs in the page.

  • PT Compact Commission Member, enacted and introduced states for the Physical Therapy Compact, with the states currently issuing privileges.
  • OT Compact Commission Member states for the Occupational Therapy Compact and the Before You Apply table of states accepting applications.
  • ASLP Interstate Compact Enacted states for audiology and speech-language pathology, and which of them issue privileges today.

Status

These are working tools built for a recruiting desk, not a released product. Compact status moves on legislative calendars: the date on the license map is when each list was last checked against the commission sites, and the tool says so on screen when that date is getting old. The deal sheet is a pre-call estimate and is not payroll.
